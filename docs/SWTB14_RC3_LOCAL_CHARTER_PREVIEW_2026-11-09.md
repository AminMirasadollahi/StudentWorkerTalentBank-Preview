**وضعیت: LOCAL REVIEW ONLY.** این مسیر به‌صورت اختصاصی در یک شاخه PR و در یک سرویس لوکال، فونت `ModamFaNumCondensed` و CSS اصلی پنل دانشجوکار را اجرا می‌کند. `OpsApp`، Supabase، Auth، ایمیل و هیچ RPC در آن بارگذاری نمی‌شوند. بدون حساب دانشجوکار، بدون تغییر اطلاعات واقعی، بدون اتصال به سامانه عمومی. **این مسیر روی GitHub Pages جاری منتشر نشده و به هیچ دانشجوکاری نمایش داده نمی‌شود.**

## چرا RC3؟

- هر کارت ارتفاع واقعی محتوای خودش را دارد (`align-items:start;align-self:start;height:auto`)؛ دیگر تا ارتفاع کارت همسایه کشیده نمی‌شود.
- هفت آیکون SVG خطی یکدست، به اندازه حدود `1.86rem` داخل باکس `3.15rem`؛ بدون کتابخانه خارجی، فونت ایموجی یا دانلود آیکون.
- بند ۵ تمام‌عرض است: **جدول واقعی سه‌ستونی** «زمان / شرایط بررسی / اقدام احتمالی» با پنج ردیف. توضیحات تکمیلی تعهد انجام‌نشده و فرصت بازبینی در `details/summary` حفظ می‌شوند. در پیش‌نمایش اختیاری می‌توان با کلیک آن را باز کرد؛ **در مرحله پذیرش اجباری آینده باید اطمینان داد کل متن، از جمله محتوای بازشونده، برای مطالعه آگاهانه در دسترس و واضح است**.
- نمایش در دو روش: فایل مستقل بدون شبکه `design/previews/SWTB14_RC3_Worker_Charter_Modal_REVIEW_ONLY.html`، یا صفحه HTML داخلی Vite `charter-preview.html` که از کامپوننت‌های React و فونت همان پروژه استفاده می‌کند.

## آزمون محلی با PowerShell 5.1 (بدون تغییر سامانه عملیاتی)

پیش‌نیاز: `git` و `node/npm` نصب باشند. در PowerShell از `npm.cmd` استفاده شده تا محدودیت اجرای اسکریپت‌های PowerShell مانع اجرای npm نشود. برای Vite 7 از Node جدید پشتیبانی‌شده (۲۰.۱۹+ یا ۲۲.۱۲+) استفاده کنید. در PowerShell:

```powershell
$ErrorActionPreference = 'Stop'
$repo = 'https://github.com/AminMirasadollahi/StudentWorkerTalentBank-Preview.git'
$branch = 'feat/swtb14-worker-agreement-rc1-modal-review-2026-11-09'
$folder = Join-Path $env:TEMP 'SWTB14_RC3_Charter_Review_20261109'
if (Test-Path -LiteralPath $folder) {
  throw 'PREVIEW_DIR_EXISTS: برای حفظ داده‌های محلی، پوشه قبلی خودکار حذف یا بازنویسی نمی‌شود.'
}
& git clone --depth 1 --single-branch --branch $branch $repo $folder
if ($LASTEXITCODE -ne 0) { throw 'GIT_CLONE_FAILED' }
Set-Location -LiteralPath $folder
& npm.cmd install --no-audit --no-fund --no-package-lock
if ($LASTEXITCODE -ne 0) { throw 'NPM_INSTALL_FAILED' }
& npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

بعد از نمایش `ready` در همین پنجره PowerShell، در Chrome باز کنید:

`http://127.0.0.1:5173/StudentWorkerTalentBank-Preview/charter-preview.html`

صفحه به‌صورت خودکار پنجره چارچوب همکاری را نشان می‌دهد. با بستن پنجره، روی «چارچوب همکاری» در سایدبار نمایشی کلیک کنید. برای توقف Vite در PowerShell کلید `Ctrl+C` را بزنید. **در یک تب دیگر سایت اصلی عملیاتی همچنان مستقل است**؛ این صفحه محلی به حساب واقعی وارد نمی‌شود. به جای اجرا در پوشه اصلی کار یا مخزن دیگر، از همین پوشه موقت مجزا استفاده کنید.

اگر `npm` یا `git` موجود نیست، فقط خطای دقیق یا شماره نسخه ابزار را گزارش کنید؛ نصب جدید/ارتقای Node را بدون بررسی محیط محلی اجبار نکنید.

## معیارهای بازبینی مالک

- فونت فارسی مدام روی عنوان، متن، جدول و دکمه‌ها نمایش داده می‌شود؛ متن قابل انتخاب و zoom تا ۲۰۰٪ است.
- کارت کوتاه، حتی اگر روبه‌روی کارت بلندتر قرار گرفته، از پایین **کش نمی‌آید**؛ بند ۵ جدول تمام‌عرض دارد.
- رنگ‌های تأکیدی ملایم هفت کارت و آیکون‌های SVG روی روشن/تیره خوانا هستند.
- توضیحات تکمیلی بند ۵ با کیبورد/کلیک باز می‌شوند و هیچ بخشی از متن حذف نشده است.
- دکمه «بستن»، کلید `Escape`، کلیک بازکردن دوباره، اسکرول و بازگشت فوکوس قابل بررسی است.
- تیک پذیرش **عمداً غیرفعال** است و هیچ پیام/سوابق/فعالیت/حساب/ثبت ساعات واقعی تغییر نمی‌کنند.
