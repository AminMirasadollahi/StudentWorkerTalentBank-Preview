# StudentWorkerTalentBank Preview

Public **UI/UX preview only** for the student-worker intake experience.

## What this repository contains

- React + Vite frontend
- Persian RTL guided form
- Modam FaNum Condensed web typography
- responsive desktop/mobile UI
- local-only draft persistence in the browser

## What this repository does **not** contain

- Supabase migrations
- database credentials
- private backend configuration
- service-role keys or secrets
- production submission logic

The final submit action is intentionally disabled in this preview.

## Source of truth

The private development repository remains the source of truth. This public repository exists only to make UI/UX review through GitHub Pages possible.
