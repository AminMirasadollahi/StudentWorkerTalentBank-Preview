SWTB17 — PR85 / آزمون محلی رابط واقعی React، فقط‌خواندنی
===================================================

هدف: بررسی نمایش نام و رشته تأییدشده در رابط واقعی مدیریت، بدون انتشار سایت و بدون اجرای SQL جدید.
منبع: Draft PR85، نه شاخه main. نام فایل build-info در پوشه dist، SHA دقیق کد را مشخص می‌کند.
این بسته را GitHub Actions فقط به‌صورت Artifact می‌سازد؛ هیچ چیزی در GitHub Pages منتشر نمی‌کند.

اجرا در Windows 11:
۱. از اجرای موفق GitHub Actions مربوط به «SWTB17 PR85 Local Read-only React QA» فایل Artifact
   به نام SWTB17_PR85_READONLY_REACT_LOCAL_QA را دانلود و ZIP را استخراج کنید.
۲. روی Start-SWTB17-PR85-Local-QA.cmd دو بار کلیک کنید. نیاز به Git/Node/npm، Administrator یا Desktop Commander ندارد.
۳. Chrome را در نشانی محلی http://127.0.0.1:<PORT>/ باز کنید. بالای صفحه نوار
   «آزمون محلی PR85 — فقط خواندن» را مشاهده کنید. این نشانی باید دقیقاً 127.0.0.1 باشد.
۴. با حساب مدیریتی خود وارد شوید (فقط در صفحه محلی؛ رمز را برای دستیار نفرستید).
   از ناوبری مدیریت، «داوطلبان» را باز کنید. اگر ابتدا «کارتابل» باز شد، طبیعی است.
۵. موارد زیر را در خودِ صفحه بررسی کنید:
   - نام و رشته فعلی برای حداقل نمونه تغییرکرده، مانند گزارش قبلی، در فهرست نشان داده می‌شود.
   - با انتخاب همان پرونده، عنوان و جزئیات فعلی نمایش داده می‌شوند؛ متن اطلاعات زمان ثبت‌نام نیز مستقل قابل مشاهده است.
   - جست‌وجوی نام/رشته جدید و تاریخی هر دو کار می‌کنند.
   - «به‌روزرسانی» فهرست هنگام خواندن، اطلاعات قبلی را پنهان و سپس دوباره نمایش می‌دهد.
   - هیچ فرمی را ثبت یا ویرایش نکنید: این نسخه شبکه را برای هر عملیات نوشتنی قطع می‌کند.
۶. دکمه «دریافت گزارش بدون اطلاعات شخصی» در نوار بالا را بزنید.
   فایل SWTB17_PR85_LOCAL_REACT_QA_SUMMARY.json را به گفت‌وگو پیوست کنید.
۷. از پنل خارج شوید و پنجره/تب آزمون و ترمینال اجرای localhost را ببندید.

محدودیت‌ها و حفاظت‌ها:
- فقط درخواست‌های مجاز به میزبان Supabase کنونی صادر می‌شود: ورود/بررسی هویت/خروج
  و RPCهای خواندنی ops_is_admin، ops_list_candidates، ops_get_operations_v3.
- تمام RPCهای ثبت/ویرایش، توابع Edge و دسترسی مستقیم جدول‌ها در fetch-guard مسدود شده‌اند.
- ساخت QA فقط از طریق پیکربندی جداگانه Vite، نگهداری نشست auth را حافظه‌ای می‌کند.
  فایل src/lib/operations.js اصلی و فایل‌های انتشار عمومی دست‌نخورده‌اند.
- ورود واقعی ممکن است زمان آخرین ورود ثبت‌شده در Supabase Auth را تغییر دهد؛ عملیات پرونده انجام نمی‌شود.
- فایل گزارش فقط نام ثابت سه تابع، مدت، اندازه بدنه، کد HTTP، شمارش مسدودسازی و SHA Build را دارد.
  ایمیل، رمز، شناسه دانشجوکار، نام/رشته، هدر و توکن را گزارش نمی‌کند.
- به‌منظور محافظت از داده‌ها، اسکرین‌شات حاوی نام، ایمیل یا شناسه واقعی ارسال نکنید.
  در صورت نیاز به تصویر، همه این فیلدها را در تصویر تار کنید.
- این نسخه برای آزمون مسیر داوطلبان است؛ ورود به بخش‌های دیگر ممکن است پیام «دسترسی مسدود»
  نشان دهد؛ از آن‌ها برای تست نوشتنی استفاده نکنید.
- این ابزار تستِ عملکرد Frontend روی حساب واقعی است، نه تأیید انتشار یا تست بازگشت Backend.
- اگر ابتدای راه‌اندازی خطا داد، فقط کد خطا را ارسال کنید. هیچ نسخه قدیمی QA را دوباره اجرا نکنید.
